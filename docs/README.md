# Silent Dominion — Game Design Documentation

> *"You are not a ruler. You are the reason rulers rise and fall."*

This is the complete, canonical documentation for **Silent Dominion**, a grand strategy / political simulation / sandbox game where the player is a single immortal human who survives by shaping — never commanding — history.

- **Source GDD version:** 0.1 — Working Draft (v14)
- **Genre:** Grand Strategy / Political Simulation / Sandbox
- **Platform:** PC (primary), Console (future)
- **Comparisons:** CK3, Victoria 3, HoI4 — but you are not the crown

---

## How to navigate this documentation

Each folder is a top-level system from the GDD. Each file is a self-contained design spec. Start with `01-vision/` to understand what the game is, then branch out based on what you are building.

## Design mantra

> The measure of success in Silent Dominion is not what you built. It is how long you lasted, and how little of it could ever be traced back to you.
