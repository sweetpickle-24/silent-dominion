# 2. The Player — The Immortal

*The player is a human being — flesh, blood, and fear — who simply does not die.*

There is no supernatural explanation the game offers. You are not a god, not a spirit, not a chosen vessel. You are a person who has been alive for a very long time, and you have learned that the only way to keep being alive is to make sure no one figures that out.

There is no avatar on screen, no character portrait. You are represented only through your actions and their consequences. But you are unmistakably human: you can be stabbed, poisoned, burned, and hanged. **The immortality is the secret. The vulnerability is the game.**
