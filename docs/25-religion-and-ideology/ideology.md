# 25.3 Ideology as Parallel Structure

Philosophical and political ideologies follow **the same structural model as religions.**

Stoicism, Confucianism, liberalism, nationalism — each has:

- Doctrinal rigidity.
- Institutional expression.
- Popular depth.
- Reform potential.
- A lifecycle.

The player's ability to manipulate an ideology follows exactly the same [Memoirs logic](../13-memoirs/README.md) as religion:

- **First encounter** requires full manual engagement.
- **Subsequent encounters** can draw on the pattern library.
