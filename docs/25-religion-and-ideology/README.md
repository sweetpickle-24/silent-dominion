# 25. Religion and Ideology — Structured Models

Religion is referenced throughout this document as a target, a tool, and a social force. It is **not modelled as a simple region-level attribute.**

Every religion in the game is a **structured entity** with its own internal attributes, power structure, geographic distribution, and lifecycle. Understanding this structure is what the [Memoirs system](../13-memoirs/README.md) encodes when the player works through a religion manually for the first time.
