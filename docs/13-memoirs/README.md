# 13. Memoirs — Pattern Recognition and Automation

The player has been alive for centuries. They have manipulated hundreds of rulers, infiltrated dozens of religions, navigated every major civilisational cycle the world has produced. At some point, **they stop thinking through every step of every operation** and start recognising patterns instantly, executing from muscle memory. The Memoirs system models this.

Memoirs are the player's accumulated expertise — a library of recognised patterns built from direct experience. Each time the player manually works through a type of situation for the first time, the game records the key variables and the approach that succeeded. When that situation recurs, the player is offered the option to automate it. **The automation is not given — it is earned through prior manual engagement.**

## Core principle

| **Stage** | **State** |
| --- | --- |
| **First encounter** | Fully manual. The player investigates, decides, executes every step themselves. |
| **Second encounter** | The game surfaces the prior pattern. The player can follow it manually with guidance, or begin automating parts of it. |
| **Established pattern** | Automation available. The player approves the approach at a high level and the game handles execution. |
| **Changed conditions** | Automation flags as uncertain. If the underlying profile has shifted since the pattern was built, the player is warned and may need to revalidate manually. |
| **Silent misfire** | If the player ignores the warning and runs a stale automation, it executes against outdated assumptions — with consequences. |
