# 33.2 Observable Conditions — What the Player Sees

| **Internal process** | **Observable condition** | **Intelligence required to see it** |
| --- | --- | --- |
| **Tax collection efficiency** | Treasury condition (flush / stable / strained / indebted / broke) | Financial network coverage or banker host in the kingdom |
| **Army maintenance** | Army morale, supply state, size category | Spy or general host near the army; military layer coverage |
| **Food distribution** | Famine risk level, grain price in markets, migration patterns | Merchant host or civic operative in the province; famine layer coverage |
| **Diplomatic activity** | Relationship score changes, alliance formations, CB accumulation | Court host or ambassador in either kingdom; diplomatic layer coverage |
| **Factional balance** | Which faction currently dominates policy | Multiple court-level sources; political layer at high coverage |
| **Population welfare** | Unrest level, loyalty to ruler, migration flows | Civilian host — merchant, priest, or minor official; social layer coverage |
