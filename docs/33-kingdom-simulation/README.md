# 33. Kingdom Simulation — The Simplified AI Model

Kingdoms run complex internal processes: tax collection, army maintenance, food distribution, diplomatic correspondence, factional management.

**The player never participates in these processes.** The simulation runs them fully, but exposes them to the player only as **observable conditions and symptoms** — never as detailed numbers requiring management.

This is how historical actors actually experienced other states, and it is the correct level of abstraction for this game.
