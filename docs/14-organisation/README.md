# 14. The Organisation — Building the Machine

The player cannot personally manage a global intelligence operation. The exposure alone would be fatal, and the cognitive load would be impossible. What the player builds over the course of the game is not a personal network — **it is a machine.**

An organisation with its own layers, its own internal logic, its own succession chains, and its own failure modes. The player sits at the top and only ever touches the layer directly below them. Everything else runs through structure.

This is how every functional shadow organisation in history has worked. **Compartmentalisation is not just a security feature — it is the fundamental architecture that makes scale possible.** The player's safety depends on distance. Their power depends on depth.
