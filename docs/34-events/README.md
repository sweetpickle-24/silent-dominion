# 34. Event System — News, Propagation, and the Action-Result Gap

Events are the game's **primary information delivery mechanism.** Everything the player learns about the world — what their organisation reports, what neutral channels carry, what official announcements state — arrives as events.

Events are **not generated randomly.** Every event has a cause, a source location, a propagation model, and a set of recipients determined by network access and geographic proximity.

**The player cannot tell whether an event was caused by their own actions, a rival society's actions, or the autonomous world simulation. This ambiguity is intentional and fundamental.**
