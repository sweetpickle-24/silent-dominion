# 28. Onboarding — Teaching the Game

Silent Dominion has approximately **twenty-five interconnected systems.** Teaching all of them without overwhelming the player is one of the most important design challenges in the project.

The solution is a **layered reveal structure**: the game begins at human scale with a minimal system surface, and unlocks new complexity organically as the player's situation naturally demands it.

## 28.1 The first session structure

The player begins in a **single city in 500 BCE** with one host and one coordinator. The table is almost bare. The map shows only the immediate city and its surrounding province. The inbox contains one letter.

**The game does not explain systems** — it presents a situation that requires the player to act, and the action teaches the mechanic.

### Tutorial by situation, not by explanation

| **Moment** | **Situation** | **What the player learns** |
| --- | --- | --- |
| **Turn 1** | A letter arrives from the coordinator introducing the host. The player reads the letter. | The inbox, the dossier system, and what a host is |
| **Week 1** | The host is being courted by a rival faction. The player must choose how to respond. | The action palette, exposure cost, and the first influence tier |
| **Month 1** | The host makes a decision that surprises the player. | Hosts have their own agency and resist direct control |
| **Month 3** | A second host opportunity appears in a neighbouring district. | Host cultivation, the city district map, and basic coverage |
| **Year 1** | A financial request arrives. | The financial network, transaction routing, and discretion cost |
| **Year 3** | A report contradicts another report. | The two-reality system and source cross-referencing |
| **Year 5–7** | The player's first host dies. | Succession, the organisation layer, and why resilience matters |

## 28.2 System unlock sequence

Systems unlock as the player's **situation demands them.** The unlock sequence is tied to organisational growth milestones rather than time, so a player who grows quickly encounters complexity quickly while a cautious player who stays small is never overwhelmed.

| **Growth milestone** | **Systems unlocked** | **Why this is the right moment** |
| --- | --- | --- |
| **First host cultivated** | Host system, action palette, exposure basics | The player has something to act on. Theory is now practice. |
| **First coordinator appointed** | Organisation layer, coverage assignments, regional dispatches | The player now has someone to delegate to. Delegation mechanics become relevant. |
| **First financial operation** | Financial network, transaction routing, discretion | Money is moving. The financial system needs to be understood. |
| **First source contradiction detected** | Two-reality system, intelligence rechecks, confidence fog | The player has experienced a misfire. The system that explains it becomes relevant. |
| **First Lieutenant appointed** | Full organisation hierarchy, succession planning, family cultivation | The player now has a real organisation. Its structure and vulnerabilities need explaining. |
| **First rival society footprint detected** | Rival society system, fingerprint investigation chain, counter-intelligence | The player is no longer alone in the shadows. Rivals become real. |
| **First owned entity founded** | Entity management, proxy structures, entity corruption | The player has structural power. The entity system becomes relevant. |
| **First base of operations move** | Travel system, transition window, route intelligence | The player is moving for the first time. Travel mechanics are introduced. |

## 28.3 The Memoirs panel as tutorial record

The Memoirs panel ([§30](./30-memoirs-panel.md)) serves a **dual purpose** as onboarding progresses:

- Its primary function is storing the player's automation library.
- Its secondary function is acting as a **living reference document** — every system the player has encountered is summarised in the Memoirs panel as a 'learned pattern', providing a reference the player can consult without leaving the table.

**The Memoirs panel is how Silent Dominion replaces the traditional help menu.**
