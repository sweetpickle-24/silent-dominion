# 7.4 The Intelligence Layer

The player's primary information source is their **host network.** Each host provides a stream of intelligence that reflects their position, personality, and loyalty. Cross-referencing multiple sources is how the player builds an accurate picture of the world.

## Bias by host type

- **A paranoid ruler's reports** will overstate threats.
- **A merchant host** will underreport political instability and overreport economic opportunity.
- **A philosopher's reports** are accurate but concern the wrong timescale.
- The player must learn to read the bias in their sources.
