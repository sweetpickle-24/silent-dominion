# 7.1 The Table

The player never sees a conventional game interface. **There are no floating menus, no HUD bars, no stat panels.** The entire game is experienced from a single perspective: a physical table covered in the tools of someone who has been running a shadow network for centuries.

Everything on the table is a real object that would exist in the world. A map spread across the surface. Letters with wax seals. A codebook. A ledger. A list of names. The player interacts with these objects directly. The world happens; the player reads about it, and responds through it.

## The table is the UI

| **Object** | **Function** |
| --- | --- |
| **Map** | The political world, drawn on era-appropriate material. Annotatable by the player. |
| **Inbox** | Sealed letters and intelligence reports arriving from the host network. |
| **Dossiers** | Detailed profiles on individuals, opened by clicking a name in any document. |
| **Ledger** | Financial threads, bribes in progress, economic pressure operations. |
| **Codebook** | Encrypted correspondence with high-value contacts. |
| **Compose** | Write letters, issue instructions, initiate actions — all as physical documents. |
| **Seal & send** | Every outgoing action is a physical letter leaving the table. |
| **Memoirs** | Leather-bound journal / codebook storing patterns ([§30](../30-memoirs-panel.md)). |

## The table evolves with the era

The table itself is a historical artifact. Its materials, tools, and objects change as centuries pass, reflecting the technology and culture of the current era. This is not cosmetic — it signals to the player where they are in history and what tools are available to them.

| **Era** | **Table materials** | **Communication tools** |
| --- | --- | --- |
| **Ancient world** | Stone surface, clay tablets, papyrus scrolls, oil lamp | Wax tablet, reed stylus, clay seal impressions |
| **Classical / Roman** | Marble or hardwood, papyrus, wax tablets, bronze instruments | Feather quill, papyrus letters, personal wax seal |
| **Medieval** | Oak table, parchment, candles, sand for blotting | Quill and ink, parchment letters, heraldic seals |
| **Early modern** | Polished wood, printed maps, glass inkwell, candelabra | Steel nib pen, paper letters, printed pamphlets |
| **Modern (1700s+)** | Bureau desk, copper-engraved maps, brass instruments | Fountain pen, newspapers, early telegraph dispatches |
