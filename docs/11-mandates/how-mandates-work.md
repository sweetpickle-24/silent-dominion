# 11.1 How Mandates Work

- The player opens the Mandate panel (a scroll or dossier on the table) and selects an active objective.
- The Mandate identifies key individuals, institutions, or events relevant to the goal.
- Progress is tracked in **phases** — each phase has conditions and a time window.
- Completing a phase unlocks context: new intelligence, new host options, deeper action choices related to this Mandate.
- **Failing a phase does not end the Mandate** — it adjusts it, sometimes opening different paths.
- Multiple Mandates can be active simultaneously, but each consumes attention and organisation bandwidth to pursue.
