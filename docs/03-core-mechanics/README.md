# 3. Core Mechanics

The player's interface with the world runs on four tightly interconnected mechanics:

- [**Host System**](./host-system.md) — attachment to individuals you cultivate; your primary interface with the world.
- [**Exposure System**](./exposure-system.md) — the 0–100 detectability score that governs what actions are available.
- [**Constraints**](./constraints.md) — the four real resources (bandwidth, capacity, exposure, time) that bound every decision.
- [**Action Palette**](./action-palette.md) — the three-tier menu of influence actions by visibility cost.

## The core loop

Every meaningful player decision touches all four:

1. **Choose a host** (or act through an existing one).
2. **Consider the action's tier** on the palette.
3. **Pay the four-constraint cost** (bandwidth, capacity, exposure, time).
4. **Wait for the result** to arrive through the [three intelligence channels](../34-events/intelligence-channels.md).
5. **Read the result through bias** — your sources have perspectives.
6. **Decide what to do next** based on an imperfect picture of the world.
