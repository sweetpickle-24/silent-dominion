# 24. Character Trait System — The Complete Specification

Every character in the world — historical figures, procedurally generated individuals, and all members of the player's organisation — is described by a **canonical set of traits.**

These traits are the foundational data model for:

- Influence calculations.
- Corruption risk.
- Weight inheritance.
- Bribery susceptibility.
- Ruler AI decisions.
- Resistance to manipulation.
