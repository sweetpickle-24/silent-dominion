# 22.2 Pre-Move Preparation

A move is prepared well before it happens. The lieutenant layer handles the operational groundwork **months or years in advance.**

- Arriving into a prepared environment is safe and seamless.
- Arriving unprepared is the most exposed state in the game.

## The pre-move checklist

| **Step** | **What it involves** |
| --- | --- |
| **Safe house established** | A coordinator in the target city has secured a base of operations for the player's arrival |
| **Courier routes rerouted** | All active source correspondence addresses are updated to route through the new location |
| **Local coordinator briefed** | The coordinator responsible for the target city has been told to expect the player and has prepared a current intelligence summary |
| **Transition window acknowledged** | A gap period of days to weeks where some reports are delayed and some sources go temporarily dark is normal and expected |
| **Old base wound down** | The previous safe house is quietly closed. No announcement. The absence is registered as the departure of an unremarkable resident. |
